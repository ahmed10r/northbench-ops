THE LOOPS (never stop, never relay)
====================================================================
  L1 AGENCY BEAT - every 5 min: creators run queued builds (<=20
     orders), hourly report check, then the HEAD patrols (state
     fingerprint; unchanged = watch, changed = think + act).
  L2 HOURLY LINE - every hour to Telegram: builder status, queue
     depth, sales count. Missing line = silence alarm (L7).
  L3 DEEP PASSES - 2x/day (09:30 courier ride + ~08:10 nightly
     wake): HEAD thinks from whole brain + 20 departments + 3
     sub-agents max; sets priorities; queues builds.
  L4 NIGHT CYCLE - ~08:00 UTC: KPI build -> brain rebuild (repo
     + CEO memory + department notes) -> site deploy -> due
     components registry update.
  L5 COURIER LOOP - daily posting pass on the 739-day calendar.
  L6 DEPARTMENT LOOPS - all 20 departments check their gauges
     every beat via the HEAD's assignment; act on movement.
  L7 SILENCE WATCHER - if the hourly line is missing 2 hours
     straight, every later beat retries + telegram_alert fires.
